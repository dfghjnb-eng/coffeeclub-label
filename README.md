# 커피클럽 라벨 프린터 (웹)

Rongta **RP420** 라벨 프린터(30mm × 15mm)용 웹 앱.
설치 없이 브라우저에서 열어 라벨을 편집하고, **WebUSB**로 바로 인쇄합니다.

👉 **https://dfghjnb-eng.github.io/coffeeclub-label/**

---

## 두 가지 인쇄 방법

### 1. 매장 인쇄 서버 — 핸드폰에서 인쇄 (아이폰 포함)

프린터가 꽂힌 **매장 맥에서 서버를 켜두면**, 같은 와이파이에 있는 폰·태블릿에서
접속해 인쇄할 수 있습니다. 폰은 라벨을 그려서 보내기만 하고, 실제 인쇄는 맥이 합니다.

매장 맥에서 **커피클럽 라벨 프린터 앱**을 열고 → `폰에서 인쇄` → **켜기**.
화면에 뜨는 주소(`http://192.168.x.x:9110`)나 QR을 폰으로 열면 끝입니다.
앱이 알아서 **매장 프린터** 모드로 바뀌고, 인쇄 버튼이 매장 맥의 프린터로 연결됩니다.

> 데스크톱 앱 없이 서버만 띄우려면 프로젝트 폴더에서 `python3 label_server.py`
> (또는 `폰인쇄서버.command` 더블클릭). 이 저장소에는 웹 화면만 들어 있습니다.

### 2. 이 컴퓨터에 직접 연결 — WebUSB

프린터가 꽂힌 컴퓨터의 **Chrome/Edge**에서 위 주소를 열고,
우측 상단 **프린터 연결** → 목록에서 프린터를 선택하면 브라우저가 USB로 직접 인쇄합니다.

처음 한 번은 자동으로 캘리브레이션(라벨 1장 소비)이 실행됩니다.

### 기기별 지원

| | 편집·미리보기 | 매장 서버로 인쇄 | USB 직접 인쇄 |
|---|---|---|---|
| Chrome / Edge (데스크톱) | ✅ | ✅ | ✅ |
| Safari / Firefox | ✅ | ✅ | ❌ |
| 아이폰 | ✅ | ✅ | ❌ |
| 안드로이드 | ✅ | ✅ | ✅ (OTG 케이블) |

## 기능

- 커피 목록 자동 동기화(Supabase) + **이름 검색**, 오프라인 캐시
- 로스팅 포인트 · 날짜 · 맛노트 · 추가 텍스트(여러 줄)
- 한글 폰트 19종 (서울한강 / 서울남산 / BM도현 / 한글누리)
- 항목별 폰트 크기, 자간·행간 조절
- **드래그로 인쇄 순서 변경**, 항목별 표시/숨김
- QR 대상 선택: 커피 정보 페이지 / 네이버 스토어 / 직접 입력
- 추가 텍스트 **프리셋** 저장·불러오기
- 커피별 설정 자동 저장 (브라우저 로컬 저장소)

## 인쇄 방식

라벨을 캔버스에 240×120 dots로 그린 뒤 600 dots 폭 캔버스의 x=130 위치에 배치하고,
1비트로 변환해 ESC/POS 래스터 명령(`ESC @` + `GS v 0`)으로 전송합니다.
데스크톱 PyQt 앱(`printer_app.py` / `label_printer.py`)과 동일한 출력 로직입니다.

## 로컬에서 실행

```bash
python3 -m http.server 8123
```

브라우저에서 `http://localhost:8123` 접속. (WebUSB는 HTTPS 또는 localhost에서만 동작합니다.)
