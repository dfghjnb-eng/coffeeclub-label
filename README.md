# 커피클럽 라벨 프린터 (웹)

Rongta **RP420** 라벨 프린터(30mm × 15mm)용 웹 앱.
설치 없이 브라우저에서 열어 라벨을 편집하고, **WebUSB**로 바로 인쇄합니다.

👉 **https://dfghjnb-eng.github.io/coffeeclub-label/**

---

## 쓰는 법

1. **Chrome**(또는 Edge)으로 위 주소를 엽니다.
2. RP420을 USB로 연결합니다.
3. 우측 상단 **프린터 연결** → 목록에서 프린터 선택.
4. 커피를 고르고 로스팅 포인트를 입력한 뒤 **인쇄**.

처음 한 번은 자동으로 캘리브레이션(라벨 1장 소비)이 실행됩니다.

### 브라우저별 지원

| | 편집·미리보기 | 인쇄 |
|---|---|---|
| Chrome / Edge (데스크톱) | ✅ | ✅ |
| Safari / Firefox | ✅ | ❌ (WebUSB 미지원) |
| 아이폰 · 안드로이드 | ✅ | ❌ |

인쇄는 **프린터가 USB로 꽂힌 그 컴퓨터**에서만 됩니다.
다른 컴퓨터에서는 라벨을 편집·확인만 할 수 있습니다.

---

## 기능

- 커피 목록 자동 동기화(Supabase) + **이름 검색**, 오프라인 캐시
- 로스팅 포인트 · 날짜 · 맛노트 · 추가 텍스트(여러 줄)
- 한글 폰트 19종 (서울한강 / 서울남산 / BM도현 / 한글누리)
- 항목별 폰트 크기, 자간·행간 조절
- **드래그로 인쇄 순서 변경**, 항목별 표시/숨김
- QR 대상 선택: 커피 정보 페이지 / 네이버 스토어 / 직접 입력
- 추가 텍스트 **프리셋** 저장·불러오기
- 커피별 설정 자동 저장 (브라우저 로컬 저장소)

## 인쇄 방식

라벨을 캔버스에 240×120 dots로 그린 뒤 600 dots 폭 캔버스의 x=130 위치에 배치하고,
1비트로 변환해 ESC/POS 래스터 명령(`ESC @` + `GS v 0`)으로 전송합니다.
데스크톱 PyQt 앱(`printer_app.py` / `label_printer.py`)과 동일한 출력 로직입니다.

## 로컬에서 실행

```bash
python3 -m http.server 8123
```

브라우저에서 `http://localhost:8123` 접속. (WebUSB는 HTTPS 또는 localhost에서만 동작합니다.)
